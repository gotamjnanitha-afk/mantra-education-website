EduLearn - Educational Website

📖 Project Description

EduLearn is a responsive educational website developed using HTML5, CSS3, and JavaScript. The website provides information about the institution, available courses, gallery, and contact details. It is designed to be user-friendly, responsive, and SEO-friendly.

✨ Features

- Responsive design for mobile, tablet, and desktop
- Home page with hero section
- About page
- Courses page
- Gallery page
- Contact page with form validation
- Simple navigation menu
- Basic SEO implementation
- JavaScript interactivity

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- Netlify
